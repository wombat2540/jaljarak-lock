# 잘자락(Lock) — Main Flows

## 플로우 1 — 온보딩 + 취침 설정

### 목적
온보딩이 끝나자마자 취침 시간 설정으로 자연스럽게 이어지는 구조.
알람 맞추듯 직관적으로 설정 완료.

### 화면 순서
1. **스플래시 화면**
   - 잘자락 로고 + 라벤더 모티프
   - 슬로건: "오늘 밤, 폰을 내려놓아요"

2. **온보딩 1**
   - 타이틀: "취침 시간이 되면 자동으로 잠가드려요"
   - 라벤더 모티프 일러스트

3. **온보딩 2**
   - 타이틀: "문제를 풀어야만 해제할 수 있어요"
   - 라벤더 모티프 일러스트

4. **온보딩 3**
   - 타이틀: "꾸준히 지키면 리워드를 드려요"
   - 라벤더 모티프 일러스트

5. **취침 시간 설정 화면**
   - 알람처럼 시간 선택 (휠 또는 시계 UI)
   - "몇 시에 잠자리에 드시나요?"

6. **차단 앱 선택 화면**
   - 설치된 앱 목록
   - 차단할 앱 선택 (복수 선택 가능)

7. **설정 완료 화면**
   - "오늘 밤 [설정 시간]에 잠금이 시작돼요"
   - 홈으로 이동

---

## 플로우 2 — 취침 모드 작동 + 해제 미션

### 목적
설정한 취침 시간이 되면 자동으로 앱이 차단되고,
해제하려면 문제를 풀어야 함.

### 화면 순서
1. **취침 모드 시작 알림**
   - 푸시 알림: "잘 시간이에요 🌿 잘자락이 시작됩니다"

2. **취침 모드 잠금 화면**
   - "지금은 취침 시간이에요"
   - 현재 시간 표시
   - 라벤더 모티프 애니메이션

3. **차단된 앱 클릭 시**
   - 잠금 오버레이 등장
   - "해제하려면 미션을 완료하세요"
   - 미션 시작 버튼 / 취소 버튼

4. **미션 화면**
   - 수학 문제 또는 단어 문제 출제
   - 난이도: 설정에서 조절 가능
   - 타이머 없음 (천천히 풀게 유도)

5. **미션 성공 화면**
   - "정답이에요! 5분만 사용할 수 있어요"
   - 제한 시간 후 자동 재잠금

6. **미션 실패 화면**
   - "다시 도전해보세요"
   - 재시도 버튼

## 플로우 3 — 리포트 + 리워드

### 목적
수면 패턴이 개선되고 있다는 걸 느끼게 해서
지속적으로 앱을 사용하게 유도.

### 화면 순서
1. **홈 화면**
   - 오늘 취침 시간 표시
   - 이번 주 준수율 표시
   - 현재 포인트 표시
   - 취침 설정 변경 버튼

2. **리포트 화면**
   - 주간 취침 시간 그래프
   - 취침 시간 준수율 (%)
   - 미션 해제 횟수
   - "지난주보다 [N]분 일찍 잠들었어요" 피드백

3. **리워드 화면**
   - 현재 포인트 잔액
   - 포인트 적립 히스토리
   - 교환 가능한 쿠폰 목록
   - 쿠폰 교환 완료 화면
